*This is an overview of all the projects in here..*


a couple of circles - Used to be a ProcessingJS program on my Khan Academy account about three years ago, transferred it to here for more freedom on the dimensions of the screen. It runs thousands of circles on a white canvas, painting it with beautiful colors as they roll around the canvas.

bogosort - A bogosort which will run until it is solved, but the thing is that it can turn theoretical; shuffling faster than a computer should be able to do. It's a test of simulating how close the bogosort is to solving after a certain amount of rolls. Got the idea from swap.'s bogosort livestreams. (https://www.youtube.com/@swapjs)

Bonkio - This holds my little monkeytamper test project that I made for https://bonk.io/. Doesn't contain anything crazy, and needs LEGENDBOSS123's mod to work, since it uses some functions directly from that mod. Thanks legend!

BonkMapEditor - Origionally created by LEGENDBOSS123, but I added player markers, distance measurer, map info, shadows, proper spawn colors, a higher-quality .png download, a .svg download, and an adjustable grid.

efficient bounces - Influenced by Powertorial, Tring to see how far I can mathematically push the computing power of this little game.

find the connect 4 - A little minigame that I thought of and made while on a trip to West Virginia. Was playing around with connect-4 and noticed that you can essentially make an infinite randomized grid with no connect-fours, nad then change one piece from blue or red or red to blue to make exactly one connect 4. Makes for a fun Where's-Waldo.

fishing game - Extremely unfinished concept of a really cool game idea. You have a fishing rod, and a pool of water shaped in a grid. Some spots on this grid has fish, some have nothing, and some have mines. You get to take a glance at the grid before it is hidden, only seeing a shadow if there is something on that grid. The problem is, the grid can be translated, rotated, have some columns or rows swapped, and you have to memorize it to get the fish. I think it's a pretty neat idea.

is this in the bible - A version of https://bible.lorte.software/ which ACTUALLY has all the words, including "a" and "i". I had to make this beacuse not having the extremely common words that are definetly in the bible bugged me for more than a day.

not so randomwalk - First .html that i've made ever.

pendulum control - Tried to make a double-pendulum-connected-to-a-car, currently only the first pendulum actualy effects the car, the second one has no affecting mass.

randomwalk - Second .html that i've made ever.

room generation - Actually a really cool concept. My attempt of generating rooms, but the rooms can scale by 16 up or down, giving a fractal-like two dimensions, like a 2d version of Fractal Block World.

Suraida - The interactive puzzle version of HEROIII's co-op sliding puzzle maps from bonk.io. I had to give it a cool japanese name..
